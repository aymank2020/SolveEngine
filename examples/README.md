# Examples

Demonstration problems for SolveEngine.

## Available Examples

- **nqueens.py** — N-Queens problem (4, 8, 12 queens)
- **sudoku.py** — 9x9 Sudoku solver
- **graph_coloring.py** — Graph coloring (Petersen graph)

## Running

```bash
python -m examples.nqueens
python -m examples.sudoku
python -m examples.graph_coloring
```
